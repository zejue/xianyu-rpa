## ✨ 功能全景

### 📦 智能发货

| 功能 | 说明 |
| :--- | :--- |
| 自动发货 | 支持固定文本、图片、卡密、第三方 API 接口，买家下单秒级自动发货 |
| 多规格发货 | 兼容无规格 / 单规格 / 多规格商品，支持多规格一键创建 SKU 发货规则 |
| 订单管理 | 自动定时查漏补缺，支持手动补发，发货明细随时可查 |
| 批量设置 | 商品导出 / 导入，批量配置发货内容，告别逐个手动设置 |

### 💬 智能客服

| 功能 | 说明 |
| :--- | :--- |
| 自动回复 | 关键词回复 + 账号级 AI 回复 + 商品级 AI 回复，秒级响应买家咨询 |
| 关键字提取 | 支持文本 / 图片关键字，基于历史消息 + 每日会话命中率智能提取 |
| 自动评价 | 买家收货后自动好评，确认收货后自动触发额外营销话术 |
| 自动催收货 | 支持一键催收货，或下单 N 天后自动提醒买家确认 |

### 🛒 商品运营

| 功能 | 说明 |
| :--- | :--- |
| 商品搬运 | 一键搬运指定卖家的多个宝贝，支持 **AI 重构文案** 去重优化 |
| 发布 / 修改 | 电脑端直接新发、编辑商品，AI 优化文案提升曝光 |
| 自动擦亮 | 一键擦亮 + 定时擦亮，持续获取平台自然流量 |

### 📊 账号与数据

| 功能 | 说明 |
| :--- | :--- |
| 一机多号 | 单台电脑最多挂载 N 个账号，每个账号独立配置运营规则 |
| 数据总览 | 基于官方数据，定时复盘访问、曝光、浏览、支付、金额、退款等核心指标 |

## 🛡️ 为什么选择本地部署？

| 优势 | 说明 |
| :---: | :--- |
| 🔐 数据安全 | 聊天记录、交易数据、商品配置**全部本地存储**，不上传云端，杜绝泄露 |
| 🌐 独立 IP | 不与他人共用服务器 IP，避免 IP 关联限流封控、异地登录风险 |
| 🪨 极致稳定 | 常用设备 + 常用网络运行，稳定，稳定，还是稳定 |
| 🤝 长期售后 | 持续更新维护，专属售后群，问题及时响应 |

## 🚀 快速开始

### 使用前提

1. 所有接入账号需已开通 **鱼小铺**；
2. 已下载程序所需的 `playwright-runtime` 压缩包与主程序 `exe`；
3. 解压后的目录结构必须如下图所示。

<!-- 📷 图片位 ⑧：解压目录结构截图（assets/screenshots/folder.png） -->
<img src="assets/screenshots/folder.png" alt="目录结构" width="60%">

### 三步上手

```
① 解压程序包，确认目录结构无误
② 双击运行主程序
③ 默认账号一键登录（本地部署，配置数据不联网），开始配置你的账号与规则
```

> 更多复杂功能（聚合聊天、批量规则、AI 文案等）请参阅仓库内《使用说明》文档。

## ❓ 常见问题

<details>
<summary><b>Q：我的聊天和交易数据会上传到云端吗？</b></summary>
<br>A：不会。系统为纯本地部署，所有数据仅存储在你自己的电脑上。
</details>

<details>
<summary><b>Q：多账号运行会不会被关联限流？</b></summary>
<br>A：系统运行在你自己的常用设备与常用网络下，拥有独立 IP，不存在云服务器多人共用 IP 的关联风险。
</details>

<details>
<summary><b>Q：没有开通鱼小铺可以用吗？</b></summary>
<br>A：暂不支持。所有功能均基于鱼小铺账号能力设计，请先开通鱼小铺。
</details>
